## 💼 LinkedIn Launch Post

```markdown
🚀 Excited to unveil my latest data analytics project: **COVID-19 Data Explorer** — an interactive macroeconomic & epidemiological intelligence dashboard built with Python, Streamlit, Plotly, and Pandas.

🔗 **GitHub Repository**: https://github.com/iamraghavmehta/covid-19-data-explorer
📊 **Tagline**: *Understanding the pandemic through data.*

### 💡 Project Overview
What began as an exploratory data analysis project with 25 analytical tasks has been transformed into a production-grade, dark-first editorial analytics platform inspired by Linear, Vercel, and Bloomberg terminal interfaces.

### 🔑 Key Engineering & Analytical Highlights:
• **Macro Scale**: Evaluates 225 global territories covering 491.5M confirmed cases and 6.18M reported fatalities.
• **100% Task Compliance**: Preserves all 25 exploratory analysis tasks from the original project specification with reproducible data cleaning pipelines.
• **Statistical Correlations**: Interactive Spearman rank correlation matrix and log-scale scatter analysis (demonstrating a 0.93 rank correlation between cumulative cases and deaths).
• **Continental Benchmarking**: Multi-metric continent groupby aggregations and territory-level dossier comparisons.
• **Editorial Dark UI**: Custom CSS theme with near-black palette (#0B0D10), responsive metric cards, and clean typography (Plus Jakarta Sans & JetBrains Mono).
• **Deployment Ready**: Streamlit Community Cloud and Nimbus-compatible with zero external database dependencies.

### 🛠️ Tech Stack:
Python | Streamlit | Pandas | NumPy | Plotly | Seaborn | Matplotlib | Git

Feedback and stars are always welcome! ⭐
```
